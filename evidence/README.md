- Входы: A/B/C_synthetic.wav и *.reference.json из модуля участника №3 (hex_app/tests/fixtures), синтезированные русские и английские голоса.

- Приведённые JSON — реальные выходы общего приложения, не ручные образцы.

## Релизный интерфейс без сети
Подписанный demo release установлен на тот же телефон. Исправлено падение холодного запуска IllegalAccessError: отключена частичная R8-оптимизация Kotlin/AndroidX; нативный код по-прежнему собирается Release.
При airplane_mode_on=1 и wifi_on=0 через системный OpenDocument импортирован stenographer-demo.wav (A_0.wav из fixtures, 7,322 с). Получены две реплики одного говорящего: 200–1820 и 2630–6612 мс. Интерфейс показал декодирование 358 мс, диаризацию 291 мс, ASR 1216 мс, полный RTF с LLM 1,205.
Отмена CreateDocument сохранила результат; повторное сохранение создало /sdcard/transcript.json. Этот файл скопирован без изменений в offline-ui-export.json; схема и границы проверены. Это проверка установленного приложения с подготовленными моделями, не чистой установки.
После проверки восстановлены исходные настройки телефона: airplane_mode_on=0, wifi_on=1.
Далее через UI в первой реплике добавлена точка и сохранена; повторное распознавание вернуло текст ASR только этой реплики, сохранив speaker_id, обе границы и вторую реплику. Звук проигрывателя этим тестом не проверялся.
Финальная сборка после добавления отдельного времени LLM в сводку: 48 JVM-тестов пройдены, инструментальные тесты скомпилированы, подписанный release APK собран.

Повтор:
`gradlew :app:installDebugAndroidTest -PevalFixtureDir=<папка fixtures>`
`adb shell am instrument -w -e class com.hex.stenographer.eval.IntegratedPipelineTest com.hex.stenographer.test/androidx.test.runner.AndroidJUnitRunner`

Отчёт и JSON сохраняются также в Android/data/com.hex.stenographer/files/integrated-eval.
