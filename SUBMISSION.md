# Сборка и запуск

## Требования
Android Studio с JDK, Android SDK 37, NDK 28.2.13676358, CMake 3.22.1.
Целевое устройство для release: Android 8.0+ (API 26), arm64-v8a.
При первой сборке компьютеру требуется интернет для загрузки зависимостей и моделей.
Веса встроены в APK; приложение обрабатывает аудио локально.

## Сборка APK
```sh
./gradlew :app:assembleRelease -PdemoSigning=true
```
В Windows используйте `gradlew.bat`. APK: `app/build/outputs/apk/release/app-release.apk`.
`demoSigning` подписывает демонстрационный APK отладочным ключом компьютера.
Без параметра release остаётся неподписанным. Для публикации в магазине нужен отдельный ключ.
При первом запуске требуется дополнительное свободное место для локальной копии весов.

Локальный кэш весов можно передать через `-PmodelCacheDir=<каталог>`; SHA-256 проверяется.
Альтернативная компактная ASR-модель: `-PasrModel=zipformer-ru`. Её качество и скорость нужно оценивать отдельно.

## Работа с приложением
1. Нажмите «Выбрать аудиофайл» и выберите WAV, MP3 либо другой поддерживаемый формат.
2. Нажмите «Создать расшифровку». При первом запуске дождитесь подготовки моделей.
3. Проверьте карточки говорящих, временные интервалы и текст.
4. Через «Редактировать» исправьте текст. Меню «Действия» позволяет прослушать реплику или распознать её заново.
5. Нажмите «Сохранить JSON» и выберите папку. Отмена сохранения оставляет результат на экране.
6. Блок «Время обработки» показывает замеры; полный RTF включает LLM, но исключает установку моделей.

[Пример фактического экспорта](evidence/offline-ui-export.json) · [Результаты проверок](evidence/README.md)

## Проверка сборки
```sh
./gradlew :app:testDebugUnitTest
```
Последняя проверка после оформления интерфейса: 48 JVM-тестов пройдены, подписанный release собран и запущен на телефоне. Сквозные замеры в evidence выполнены до изменения оформления интерфейса.

## Ограничения
- Одновременные голоса не разделяются: в перекрытии сохраняется один голос.
- Диаризация не прерывается посередине нативного вызова.
- Повторная обработка реплики декодирует весь исходный файл, но распознаёт выбранный интервал.
- Ручные правки не пересчитывают замеры первоначального прогона.
- Ошибки ответа LLM и превышение бюджета приводят к сохранению исходного ASR-текста.
- GPU/NPU-ускорение не реализовано. Скорость зависит от устройства; холодный вызов LLM может быть длительным.
- Чистая установка в авиарежиме и точность остановки воспроизведения отдельно не подтверждены. Проверка офлайн-обработки выполнена с уже установленными моделями.
